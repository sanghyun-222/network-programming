# 파이썬 연습문제풀이 업로드

## 1. 기본 연산 및 수식
- `1-1.py` : 두 수를 입력받아 사칙연산을 수행합니다.
- `1-3.py` : 여러 수식과 수학 공식을 계산합니다.

## 2. 조건문과 반복문
- `2-1.py` : 두 리스트의 내적을 계산합니다.
- `2-2.py` : 학번과 이름을 딕셔너리에 저장하고 조회합니다.
- `2-3.py` : 1부터 100까지 홀수와 짝수를 구분합니다.
- `2-4.py` : 1부터 100까지 3과 5의 배수를 구분합니다.
- `2-5.py` : 입력한 연도가 윤년인지 확인합니다.
- `2-6.py` : 2부터 100까지의 소수를 찾습니다.

## 3. 함수
- `3-1.py` : 여러 수의 덧셈과 곱셈을 함수로 계산합니다.
- `3-2.py` : 입력한 수들의 최솟값과 최댓값을 구합니다.
- `3-3.py` : 문자열에서 모음의 개수를 계산합니다.

## 4. 파일 입출력
- `4-1.py` : 파일 내용을 줄 번호와 함께 출력하고 저장합니다.
- `4-2.py` : 파일의 문자, 단어, 줄 수를 계산합니다.
